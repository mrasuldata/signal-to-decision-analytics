# Source-data reuse screen

Checked against publisher or federal catalog statements on 2026-09-26. This screen concerns the *analyzed data*, not a guarantee that an API will always be available or that government names/logos may be used for endorsement. The package uses numerical or structured fields and does not republish complaint narratives.

| Project | Basis for no-fee, no-required-attribution data reuse |
|---|---|
| 01 | [CFPB Consumer Complaint Database](https://www.consumerfinance.gov/data-research/consumer-complaints/) says the published complaint data are freely available for anyone to use, analyze, and build on. |
| 03 | [FDIC Institution Financial and Regulatory Data federal catalog](https://catalog.data.gov/dataset/institution-financial-and-regulatory-data) identifies the BankFind financial-data distribution as U.S. public domain with unrestricted use. |
| 04 | [CMS hospital data dictionary](https://data.cms.gov/provider-data/sites/default/files/data_dictionaries/hospital/HOSPITAL_Data_Dictionary.pdf) states public-reporting data are public domain; attribution is appreciated, not required. |
| 05 | [openFDA terms](https://open.fda.gov/terms/) designate data CC0/public domain unless an exception applies; the [drug-shortages endpoint](https://open.fda.gov/apis/drug/drugshortages/) does not flag such an exception. API access conditions are separate from data reuse. |
| 07 | [EIA reuse policy](https://www.eia.gov/about/copyrights_reuse.php) says government data and files are public domain; acknowledgment is recommended, not a license condition. |
| 08 | [EPA eGRID FAQ](https://www.epa.gov/egrid/frequent-questions-about-egrid) expressly allows commercial and noncommercial use as public domain. |
| 10 | [BLS copyright statement](https://www.bls.gov/opub/copyright-information.htm) says published material is public domain and may be reused without specific permission; this analysis uses numerical series, not excluded photos or the BLS emblem. |

Free download alone was not treated as proof of unconditional reuse. If a future publisher response includes separately licensed material, do not add it to this package without a new rights check.
